# ⚖️ Nyaya Sahayak – AI-Powered Legal Awareness Assistant

Nyaya Sahayak is an AI-based legal awareness chatbot designed to help users understand Indian laws in a simple and accessible manner. The system provides clear, contextual, and reliable legal information related to Indian statutes through a conversational interface.

---

## 🎯 Project Objective

The primary objective of Nyaya Sahayak is to democratize access to legal knowledge by enabling users to ask legal questions in natural language and receive accurate, easy-to-understand responses strictly related to Indian law.

---

## 🛠️ Technologies Used

- **Python 3**
- **Streamlit** – Web interface
- **LangChain** – Prompt and message handling
- **Groq API (LLaMA 3.1)** – Large Language Model inference
- **dotenv** – Environment variable management

---

## ⚙️ Key Features

- Natural language legal query support
- Focused on Indian laws (BNS 2023, IT Act, Consumer Law, etc.)
- Built-in guardrails to block non-legal questions
- Session-based conversation handling
- Clean and user-friendly UI

---

## 🔐 Security Note

API keys are stored securely using environment variables (`.env`) and are excluded from version control using `.gitignore`.
